# foxcheeks Telegram Mini App

Миниапка для поэтапного сбора заявки на татуировку.

Демо: https://Rol1s.github.io/foxcheeks-mini-app/

## Что внутри

- Dark premium оформление под tattoo-направление.
- Бренд: `foxcheeks`.
- Только русский язык.
- Поэтапная заявка:
  1. Услуга: татуировка / перекрытие
  2. Идея
  3. Место и размер
  4. Стиль и цвет
  5. Референсы
  6. Комментарий мастеру
  7. Выбор даты и времени
- Экран проверки заявки перед отправкой.
- Разделы: новая заявка, мои заявки, FAQ, помощь.
- Отправка заявки в Telegram через `Telegram.WebApp.sendData`.

## Локальный просмотр

Сервер уже можно поднять из этой папки:

```powershell
python -m http.server 5178
```

Адрес для просмотра в браузере:

```text
http://localhost:5178
```

## Подключение к Telegram

Telegram Mini App должна быть доступна по публичному HTTPS-адресу.

После публикации сайта вставьте ссылку в файл бота:

```text
tattoo_telegram_bot/.env
```

```env
MINI_APP_URL=https://Rol1s.github.io/foxcheeks-mini-app/
```

После этого перезапустите бота. В меню появится кнопка `Открыть миниапку`.
